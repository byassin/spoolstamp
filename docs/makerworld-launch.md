# MakerWorld launch checklist

## Release gate

- Public repository, license, notices, and contribution policy are live.
- Hosted app is live and the repository link is visible.
- CI passes on the release commit.
- A generated project 3MF imports into current Bambu Studio with the selected presets/colors and zero geometry repairs; desktop slicing and actual spool assignments are verified before release.
- Every distributed template has a recorded source, applicable license, and required attribution.
- The supplied dry-box template's public distribution terms are verified; it is not presented as original MIT geometry.
- The listing says clearly that direct printer send still requires Bambu Studio.

## Suggested listing

**Title:** Filament Label Lab — generate Bambu filament labels in your browser

**Summary:** Pick an official Bambu filament color, choose a label style and target printer, preview the exact model geometry in 3D, and download a color-aware 3MF with raised text.

**Key points:**

- 314 official profile colors and 14 printer models.
- Multiple label formats with recorded template provenance.
- Gradient, split-color, and transparent profile definitions retained as appearance metadata; printable material roles remain explicit.
- No account or printer credentials required.
- Open-source generator and reproducible catalog pipeline.

**Required disclosure:** This is an independent community project and is not affiliated with or endorsed by Bambu Lab. Downloads are unsliced project 3MFs with a disclosed Bambu importer compatibility identifier and explicit Filament Label Lab provenance. Open as a project with matching system presets installed, map the two project filaments to actual spools, then slice and inspect before printing. Trust confirmation may still be required.

## Launch assets still needed

1. A cover image showing the app plus one printed label.
2. One original demo 3MF generated by the public release.
3. A physical hinge coupon, dry-box fit check, retention test, and cycle-test results for a representative 0.4 mm nozzle workflow.
4. A short screen recording of select → preview → download → Bambu Studio import.
5. Optional written permission from community creators before any licensed adapter is featured.

Publishing the MakerWorld listing is an account-level external action and should happen only after the maintainer reviews the final copy and assets.
