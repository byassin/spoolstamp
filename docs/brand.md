# Spoolstamp

Spoolstamp is a filament label studio. The name connects the filament spool with the small, physical mark used to identify it. It is a project name, not a claim of trademark clearance or Bambu Lab affiliation.

## Identity

- Mark: `public/brand/spoolstamp-mark.png` — an S-shaped filament coil with an integrated tag.
- Primary accent: lime `#B7F36B`.
- Canvas: charcoal `#111416`; panels: `#1A1E21`.
- Type: Geist for the interface. The separate Noto Sans print font is unchanged.
- Use the mark with a live-text **Spoolstamp** wordmark. Keep it separate from Bambu trademarks.

The logo was generated using the built-in image-generation tool, not a CLI/API fallback. It is used as a square raster mark in the header and favicon. No third-party logo was supplied as a reference.

## Generation prompt

```text
Use case: logo-brand
Asset type: original raster logo mark for Spoolstamp, a professional maker design tool for filament labels.
Primary request: one compact distinctive geometric symbol combining a coiled filament, a single continuous S-shaped stroke, and a small label/tag silhouette integrated into the same mark. The S is an abstract shape, not typeset lettering.
Style/medium: extremely crisp flat vector-like raster graphic, minimal, strong silhouette, balanced negative space, thick simple geometry that reads clearly at 32 pixels.
Composition/framing: square canvas; single centered mark filling approximately 80 percent of the canvas.
Color palette: vivid lime #B7F36B mark on a perfectly solid deep neutral charcoal #111416 background.
Constraints: one original symbol only; no letters, no wordmark, no text, no Bambu marks, no gradients, no shadows, no textures, no mockup, no 3D, no border, no watermark. Avoid intricate internal lines or tiny details.
```

The actual generated raster has slight tonal variation; the production interface colors above are exact CSS values.
